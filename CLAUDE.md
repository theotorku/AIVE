# CLAUDE.md

# Project

ProPlan AI Visibility Platform

Core Product:
Agent Business Index (ABI)

---

# Mission

Help businesses become understandable to AI.

Every technical decision should support one of:

- AI Understanding
- AI Retrieval
- AI Recommendation
- Agent Readiness
- Semantic Authority

---

# Product Philosophy

We are NOT building:

- a generic scraper
- a markdown converter
- a crawler API

We ARE building:

- AI Visibility Infrastructure
- Agent Readiness Infrastructure
- Semantic Business Intelligence

---

# Core Rule

Before implementing any feature ask:

Does this improve ABI?

If the answer is no:

Do not build it.

---

# Current Goal

Build ABI MVP.

Success Criteria:

1. Crawl website
2. Extract business intelligence
3. Calculate ABI score
4. Generate recommendations
5. Produce downloadable report

# Architecture Principles

1. Simplicity over sophistication

Prefer:

simple working systems

over

complex unfinished systems

---

2. Business value over technical elegance

Optimize for:

useful ABI reports

not architectural perfection

---

3. Validation over expansion

Do not build future roadmap items until:

- ABI works
- audits are delivered
- customers provide feedback
